# Dataset Setup

Download `WA_Fn-UseC_-HR-Employee-Attrition.csv` from the [IBM HR Analytics Employee Attrition and Performance dataset on Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) and place it in this folder.

The expected local path is:

```text
data/WA_Fn-UseC_-HR-Employee-Attrition.csv
```

The notebook validates the expected 1,470 rows, 35 source columns, target labels, missing values, duplicates, and excluded constant or identifier fields before modeling.

The source CSV is not redistributed in this repository. Kaggle describes it as a fictional dataset and lists its license as “Database: Open Database, Contents: Database Contents.” Review the current terms on the source page before reuse.
